# Retail Business Database

This is an independent PostgreSQL project built to practise relational database design, SQL queries, and data verification.

## Database Structure
The database contains five related tables:
- Customers
- Products
- Orders
- Order Items
- Payments

## SQL Skills Demonstrated
- Creating tables and inserting records
- Primary keys and foreign keys
- Data types and constraints
- Querying and verifying records
- Organising SQL scripts

## Data Quality Skills
Through learning and practice, I am developing skills in:
- Checking records for missing or inconsistent information
- Reviewing data for accuracy
- Applying consistent labels and categories
- Following data annotation guidelines
- Documenting uncertain cases for review

## Tools
- PostgreSQL 15
- pgAdmin 4
- SQL

This is an independent learning project using practice data. Data annotation skills are being developed through learning and practice; no paid professional annotation experience is claimed.
